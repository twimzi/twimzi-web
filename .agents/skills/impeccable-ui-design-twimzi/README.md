# Impeccable UI Design — Twimzi

A Twimzi-specific skill for UI/UX work in the Twimzi Next.js website and Flutter Android app. It adapts the official Impeccable workflow and vocabulary; it is not the official Impeccable runtime.

## Installation in this repository

The skill lives at:

`.agents/skills/impeccable-ui-design-twimzi/SKILL.md`

This is a repository-local Agent Skills location used by compatible coding agents such as Codex. After pulling the branch/repository, restart or reload the coding agent if needed and ask:

- “Use Impeccable UI Design — Twimzi to audit the homepage.”
- “Apply Impeccable principles to polish the business profile.”
- “Use the skill to improve the Flutter community screen.”

## Using it in ChatGPT

This repository file is reusable prompt content, not an installed skill in a ChatGPT account. If your ChatGPT interface/workspace supports custom skill uploads, use the `SKILL.md` file there. Otherwise, attach/open the file in a Project or paste its contents into the relevant project instructions. Merely committing it to GitHub does not activate it inside ChatGPT.
